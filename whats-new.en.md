# New in version 1.6.0

| What changed                 | What you get                                                                                                                                                                                                                                                                                                                              |
| ---------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Player and media library     | A full-screen media scene plays local audio and video files, preserves the queue, keeps playing in the background, and provides a pinnable hover panel, a separate fullscreen mode, and auto-hiding controls. Compatible local files switch audio tracks natively, while codecs unsupported by Chromium are prepared in one load-limited HLS session with adaptive seeking and temporary-cache cleanup. The Now Playing card uses a music fallback icon for MP3 and other audio files and does not show a broken image when a poster fails |
| Redesigned Settings          | Settings now use a lightweight two-column layout with localized parameter search, sticky headers, compact runtime details, modern switches and choice cards, responsive navigation, and complete keyboard operation                                                                                                                     |
| Windows tray panel           | Right-clicking the Thunder tray icon opens a compact Windows 11-style panel with system-theme support, quick actions, and full keyboard navigation                                                                                                                                                                                        |
| Subtitle downloads           | Quality selection now includes a **Subtitles tab** that saves tracks in **.SRT** format                                                                                                                                                                                                                                                   |
| Format converter             | A new **tool** was **added** for converting an audio or video file with `ffmpeg`                                                                                                                                                                                                                                                          |
| Tools                        | The tab now has persistent responsive navigation, while **yt-dlp**, **ffmpeg**, and **Deno** management provides an overall status, update checks, per-tool installation, and safe reinstallation with rollback to the previous binary on failure                                                                                          |
| Tool settings                | The **Tools** section was removed from Settings: Tools and Backup are now always available, without auto-send or restoring the last opened tool                                                                                                                                                                                          |
| Downloader mode switch       | The **Detailed / Compact** switch was moved to the URL hint row and now displays the selected mode as text next to the icons                                                                                                                                                                                                              |
| Keyboard shortcut management | Keyboard shortcuts were moved to a dedicated Settings section: every action can be searched, reassigned with conflict detection, reset, and transferred via configuration export/import                                                                                                                                                   |
| Player keyboard shortcuts    | Added configurable commands for playback, queue navigation, seeking, volume, fullscreen, the media library, shuffle, repeat, and current-file information                                                                                                                                                                                 |
