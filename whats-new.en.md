# New in version 1.6.6

| What changed                 | What you get                                                                                                                                                                                                                                                         |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| New Thunder app icon         | The refreshed T-shaped download mark appears in the app, on the Windows taskbar, and as the website's installable app icon.                                                                                                                                          |
| Sidebar navigation           | App sections now live in a persistent sidebar. Tools open from a nested menu that adapts to the window width.                                                                                                                                                      |
| Format window                | Open list formatting in its own independently movable window from the sidebar.                                                                                                                                                                       |
| WG Unlock                    | Removed the tips card to free up space in the tool panel.                                                                                                                                                                                                         |
| Preview and format selection | Link checks, the preview card, and quick video, audio, and subtitle selection now form one flow. The compact URL field keeps folder and batch-review actions close at hand and hides long labels after a preview appears. The card appears above the field, and the downloader heading smoothly hides. |
| Multiple links and playlists | A review screen summarizes found, duplicate, and unsupported links before adding them. For playlists, choose individual videos and add them to the queue with one shared media profile.                                                                              |
| Download queue               | The queue is split into **Active**, **Next**, and **Needs attention**. Cards show stages, speed, transferred size, and time remaining; pending jobs can be reordered, while failures can be reviewed and retried manually. Download progress messages are localized. |
| Quick access                 | Open the latest video, downloads folder, or History from one panel. The count shows all history entries; when History is hidden, a new entry highlights the button and marks it as new.                                                                              |
| Built-in player removed | The app now focuses on downloads and media tools. |
| Bulk actions in History      | Page and filter-result selection now live in the History controls. The bulk actions bar appears when entries are selected and supports exporting or deleting them; controls are easier to use in narrow windows.                                                     |
