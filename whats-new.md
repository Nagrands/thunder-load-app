# Thunder Spark — 1.6.0

| Изменения                                      | Что это даёт                                                                 |
| ---------------------------------------------- | ---------------------------------------------------------------------------- |
| **Запущен** бренд Thunder                      | Название продукта обновлено до Thunder без редизайна рабочих экранов         |
| **Добавлена** основа Thunder Spark             | Версия 1.6.0 получила официальный релизный коднейм Thunder Spark и слоган `Spark ignites the future of downloads.` |
| **Подготовлены** бренд‑документы               | Brand Guide, правила логотипа, цвета, типографика, иконки и naming готовы для следующих фаз |
| **Добавлены** бренд‑ассеты                     | SVG‑логотипы, lightning‑circle symbol, favicon и шаблоны для релизов, GitHub, splash и installer лежат в `assets/brand` |
| **Обновлена** общая оболочка интерфейса        | Topbar, footer, кнопки, формы, меню, подсказки, модальные окна и прогресс используют Thunder‑токены |
| **Добавлен** локальный веб-интерфейс загрузчика | Его можно включить в настройках и управлять загрузками из браузера на этом компьютере |
| **Сохранена** совместимость данных             | Настройки и история продолжают использовать историческую папку Thunder Load   |
