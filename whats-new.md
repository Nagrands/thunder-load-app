# Новое в версии 1.6.4

| Изменения                     | Что это даёт                                                                                                                                                                                                                                                                                                                              |
| ----------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Надёжное завершение работы    | Централизовано завершение Плеера, загрузок, инструментов и Web Control без оставшихся процессов **yt-dlp** и **FFmpeg**                                                                                                                                                                                                                   |
| Диагностика                   | Добавлены локальные журналы с уровнями событий, подробным режимом и безопасным экспортом диагностического ZIP-пакета в Настройках                                                                                                                                                                                                         |
| Доступность интерфейса        | Контекстные меню, уведомления, индикаторы прогресса, фокус и reduced motion приведены к общему доступному поведению в Desktop и Web Control                                                                                                                                                                                               |
| Адаптивный интерфейс          | Desktop сохраняет привычную плотность в обычном окне и полноценно работает от **800×500** и при увеличенном масштабе: навигация, Downloader, История, Настройки, Инструменты, Formatter и Плеер перестраиваются без обрезанных действий, а контекстное меню Истории остаётся в границах окна; Web Control лучше использует экран телефона |
| Обновлённый Downloader        | URL, папка назначения, превью и быстрый выбор Video, Audio и Subtitles объединены в один последовательный сценарий; карточка предпросмотра перестраивается по доступной ширине без узких колонок, лишних переносов и обрезанных действий, а пакетная загрузка получила проверку нескольких URL и выбор отдельных элементов плейлиста с единым media-профилем                                                       |
| Очередь загрузок              | Очередь разделена на **Активные**, **Далее** и **Требуют внимания**: активные карточки показывают реальные этапы, объём, скорость и ETA, ожидающие задачи поддерживают приоритет и перетаскивание, а ошибки предлагают подходящие действия без автоматических повторов                                                                       |
| История загрузок              | История использует единый постраничный список, автоматически синхронизируется и хранится атомарно; добавлены фильтр доступности, устойчивое выделение между страницами и фильтрами, компактная панель массовых действий с иконками и подсказками, выбор страницы или всех результатов состояния, удаление и экспорт выбранных записей, а поиск при пустой выдаче можно явно сбросить |
| Плеер и медиатека             | Добавлена новая вкладка **Плеер**. Это полнооконная медиасцена, которая воспроизводит локальные аудио- и видеофайлы, сохраняет очередь, продолжает играть в фоне и предоставляет закрепляемую боковую-панель, отдельный полноэкранный режим и автоскрывающиеся элементы управления.                                                       |
| Управление окном Плеера       | В Медиатеке Windows появились кнопки сворачивания и закрытия окна, а кнопка закрытия в самом Плеере теперь завершает только воспроизведение текущего файла, не удаляя его из медиатеки или очереди                                                                                                                                        |
| Новое окно настроек           | Настройки получили лёгкий двухколоночный интерфейс, локализованный поиск по параметрам, закреплённые заголовки, компактные сведения о runtime, современные переключатели и карточки выбора, адаптивную навигацию и полное управление с клавиатуры                                                                                         |
| Инструменты                   | Вкладка получила постоянную адаптивную навигацию, а управление **yt-dlp**, **ffmpeg** и **Deno** — общий статус, проверку обновлений, индивидуальную установку и безопасную переустановку с восстановлением предыдущего бинарника при ошибке                                                                                              |
| Управление горячими клавишами | Горячие клавиши перенесены в отдельный раздел настроек: все действия можно искать, переназначать с проверкой конфликтов, сбрасывать и переносить через экспорт/импорт конфигурации                                                                                                                                                        |
| Горячие клавиши плеера        | Добавлены настраиваемые команды воспроизведения, очереди, перемотки, громкости, полноэкранного режима, медиатеки, перемешивания, повтора и информации о текущем файле                                                                                                                                                                     |
