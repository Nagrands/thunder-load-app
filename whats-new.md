# Новое в версии 1.6.0

| Изменения                       | Что это даёт                                                                                                                                                                                                                     |
| ------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Плеер и медиатека               | Полнооконная медиасцена воспроизводит локальные аудио- и видеофайлы, сохраняет очередь, продолжает играть в фоне и предоставляет закрепляемую hover-панель, отдельный полноэкранный режим и автоскрывающиеся элементы управления |
| Скачивание субтитров            | В выборе качества появилась **вкладка «Субтитры»** с сохранением дорожек в формате **.SRT**                                                                                                                                      |
| Конвертер форматов              | **Добавлен** новый **инструмент** для конвертации аудио или видеофайла через `ffmpeg`                                                                                                                                            |
| Инструменты                     | **Управление** зависимостями **yt-dlp**, **ffmpeg** и **Deno** перенесено из **настроек** загрузчика во вкладку **Инструменты**                                                                                                  |
| Переключатель режима загрузчика | Переключатель **«Подробно / Компактно»** перенесён в строку подсказки URL и теперь показывает выбранный режим текстом рядом с иконками                                                                                           |
| Управление горячими клавишами   | Горячие клавиши перенесены в отдельный раздел настроек: все действия можно искать, переназначать с проверкой конфликтов, сбрасывать и переносить через экспорт/импорт конфигурации                                               |
