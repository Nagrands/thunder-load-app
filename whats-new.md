# Новое в версии 1.7.1

| Изменения             | Что нового                                                                                                 |
| --------------------- | ---------------------------------------------------------------------------------------------------------- |
| Боковая навигация     | Нижнее меню заменено постоянной боковой панелью. Инструменты собраны во вложенном меню.                    |
| Обновлённый загрузчик | Переработаны поле ссылки, предпросмотр и выбор качества; можно просматривать несколько ссылок и выбирать видео из плейлистов. |
| Очередь загрузок      | Задачи сгруппированы по состоянию, ожидающие загрузки можно упорядочивать.                                  |
| Инструменты           | Обновлены экран инструментов, конвертер и инспектор медиа. Форматирование списков вынесено в отдельное окно, файловый сортировщик удалён. |
| Веб-панель управления | Добавлены боковая навигация и обновлённое отображение очереди.                                             |
| Выбор субтитров      | При выборе субтитров селекторы видео и аудио блокируются, чтобы было понятно: загрузятся только субтитры. При отключении субтитров выбор видео и аудио снова доступен. |
| Встроенный плеер      | Удалён, чтобы сосредоточить приложение на загрузках и инструментах обработки медиа.                        |
