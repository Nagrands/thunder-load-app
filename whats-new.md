# Новое в версии 1.6.0

| Изменения                               | Что это даёт                                                                                                                                                                                                                                                                                                                           |
| --------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Скачивание субтитров                    | В выборе качества появилась **вкладка «Субтитры»** с сохранением дорожек в формате **.SRT**                                                                                                                                                                                                                                            |
| Конвертер форматов                      | **Добавлен** новый **инструмент** для конвертации аудио или видеофайла через `ffmpeg`                                                                                                                                                                                                                                                  |
| Окно выбора качества                    | **Добавлены** плавные анимации открытия модального окна, переключения вкладок и появления превью после загрузки                                                                                                                                                                                                                        |
| Инструменты                             | **Управление** зависимостями **yt-dlp**, **ffmpeg** и **Deno** перенесено из **настроек** загрузчика в **отдельный инструмент**                                                                                                                                                                                                        |
| Открытие вкладки «Инструменты»          | Шапка и карточки инструментов теперь появляются плавно и последовательно при каждом переходе на вкладку, а системная настройка уменьшения движения полностью учитывается                                                                                                                                                              |
| WinGet Installer                        | - Статусы **WinGet** проверяются через JSON-вывод, а запуск возвращает структурированные ошибки и итог по выбранным пакетам. <br>- Остановка запуска на **Windows** завершает дерево процесса **PowerShell/winget** и понятнее отображает отмену. <br>- При запуске сценария фокус переносится на блок лога с выполняющейся операцией. |
| Media Inspector                         | **Добавлено** перетаскивание файлов и отдельное состояние предупреждений                                                                                                                                                                                                                                                               |
| Переключатель режима загрузчика         | Переключатель **«Подробно / Компактно»** перенесён в строку подсказки URL и теперь показывает выбранный режим текстом рядом с иконками                                                                                                                                                                                                 |
| **Исправлена** проверка yt-dlp на macOS | Thunder больше не запускает Python-backed `yt-dlp`, чтобы macOS не показывала повторную проверку `Python.framework`                                                                                                                                                                                                                    |
| Настройки приложения                    | Блок версий стал компактнее: оставлены версии Thunder и Electron, а действия представлены иконками с доступными всплывающими подсказками                                                                                                                                                                                               |
| Управление горячими клавишами            | Горячие клавиши перенесены в отдельный раздел настроек: все 16 действий можно искать, переназначать с проверкой конфликтов, сбрасывать и переносить через экспорт/импорт конфигурации                                                                                                                                                     |
| Поле ввода URL                          | Иконка источника теперь мгновенно меняется на иконку YouTube, Twitch, VK Видео или Coub при распознавании ссылки и возвращается к глобусу после очистки поля                                                                                                                                                                           |
| Компактный выбор качества               | В компактном режиме оставлены только параметры видео и аудио; выбор субтитров остаётся доступен в полном окне качества                                                                                                                                                                                                                 |
| Диагностика интерфейса                  | Проверка обязательных DOM-элементов теперь выполняется один раз при запуске интерфейса и не создаёт ложных ошибок при загрузке отдельных модулей                                                                                                                                                                                        |
| Переключение вкладок                    | Быстрое переключение вкладок горячими клавишами больше не скрывает содержимое активной вкладки после завершения анимации                                                                                                                                                                                                                |
| Релизный workflow                       | Публикация macOS и Windows сборок выполняется последовательно, чтобы GitHub Release не создавался дважды для одного тега                                                                                                                                                                                                               |
