# 1.6.0

| Изменения                               | Что это даёт                                                                                                                    |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| **Thunder Spark**                       | Версия 1.6.0 получила официальный релизный коднейм **Spark** и слоган `Spark ignites the future of downloads.`                  |
| Предпросмотр видео                      | Длительность теперь отображается на превью-картинке, а live player получил заголовок, метаданные и компактный вид               |
| Скачивание субтитров                    | В выборе качества появилась вкладка «Субтитры» с сохранением RU/EN дорожек в SRT                                                |
| Cookies для YouTube                     | В настройках загрузчика можно передать cookies из браузера или файла cookies.txt для роликов, требующих вход или проверку       |
| Cookies для YouTube                     | Browser-cookies применяются только к YouTube-ссылкам, чтобы не вызывать лишние запросы Keychain на других источниках            |
| **Исправлено** скачивание субтитров     | Языки с регистрозависимыми кодами вроде `pt-BR` и `zh-Hans` передаются без искажений, а найденные VTT/TTML конвертируются в SRT |
| **Исправлено** скачивание субтитров     | Thunder устойчивее находит файлы субтитров, которые yt-dlp сохраняет после конвертации или как auto captions                    |
| **Исправлено** скачивание субтитров     | При выборе переведённых auto captions Thunder скачивает только выбранную дорожку и больше не смешивает её с оригиналом          |
| Запуск приложения                       | Проверка обновлений теперь стартует после готовности окна, а main process получил метки для поиска узких мест запуска          |
| Запуск приложения                       | История загрузок больше не блокирует первый готовый экран и загружается в фоне без повторного чтения счётчика                  |
| Запуск приложения                       | Вкладки «Инструменты» и «Продукты» теперь догружают тяжелые модули только при открытии                                        |
| Запуск приложения                       | Проверка доступности `yt-dlp`, `ffmpeg` и Deno теперь проходит без раннего запуска бинарников                                 |
| Запуск приложения                       | Backup-модуль больше не загружается вместе с общими IPC-обработчиками и подключается только при backup-действиях              |
| Запуск приложения                       | Обработчики папки инструментов вынесены из общего IPC-модуля и покрыты отдельными проверками миграции бинарников              |
| Запуск приложения                       | IPC проверки версий и доступности инструментов вынесен в отдельный модуль с сохранением macOS-логики ffmpeg                   |
| Запуск приложения                       | Dev-обработчики update-уведомлений вынесены из общего IPC-модуля и покрыты отдельными тестами событий                         |
| Запуск приложения                       | IPC ручной проверки, загрузки и установки обновлений вынесен в отдельный модуль updater-команд                                |
| Очередь загрузок                        | Фильтры очереди переехали в заголовок, статусы с нулевыми счётчиками больше не занимают место, а лишние bulk-кнопки удалены     |
| Очередь загрузок                        | Кнопка «Все» убрана, а общее количество задач теперь показано рядом с заголовком «Очередь»                                      |
| История загрузок                        | Раскрытая запись получила крупное превью и аккуратные строки деталей для источника, файла, качества, размера и даты             |
| **Исправлена** история загрузок         | Превью больше не перекрывает детали, а кнопка Play открывает скачанный файл вместо просмотра картинки                           |
| **Исправлена** проверка yt-dlp на macOS | Thunder больше не запускает Python-backed `yt-dlp`, чтобы macOS не показывала повторную проверку `Python.framework`             |
