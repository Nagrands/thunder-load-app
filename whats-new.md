# Новое в версии 1.6.0

| Изменения                       | Что это даёт                                                                                                                                                                                                                                                                                                                                                     |
| ------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Плеер и медиатека               | Полнооконная медиасцена воспроизводит локальные аудио- и видеофайлы, сохраняет очередь, продолжает играть в фоне и предоставляет закрепляемую hover-панель, отдельный полноэкранный режим и автоскрывающиеся элементы управления. Совместимые локальные файлы переключают аудиодорожку нативно, а неподдерживаемые Chromium кодеки автоматически подготавливаются в одном HLS-сеансе с ограниченной нагрузкой, адаптивной перемоткой и очисткой временного кэша |
| Панель трея Windows             | Правый щелчок по значку Thunder открывает компактную панель в стиле Windows 11 с системной темой, быстрыми действиями и полным управлением с клавиатуры                                                                                                                                                                                                          |
| Скачивание субтитров            | В выборе качества появилась **вкладка «Субтитры»** с сохранением дорожек в формате **.SRT**                                                                                                                                                                                                                                                                      |
| Конвертер форматов              | **Добавлен** новый **инструмент** для конвертации аудио или видеофайла через `ffmpeg`                                                                                                                                                                                                                                                                            |
| Инструменты                     | Вкладка получила постоянную адаптивную навигацию, а управление **yt-dlp**, **ffmpeg** и **Deno** — общий статус, проверку обновлений, индивидуальную установку и безопасную переустановку с восстановлением предыдущего бинарника при ошибке                                                                                                                                                                                      |
| Настройки инструментов          | Раздел **«Инструменты»** удалён из настроек: Tools и Backup теперь доступны всегда, без автоотправки и восстановления последнего открытого инструмента                                                                                                                                                                                                                                                    |
| Переключатель режима загрузчика | Переключатель **«Подробно / Компактно»** перенесён в строку подсказки URL и теперь показывает выбранный режим текстом рядом с иконками                                                                                                                                                                                                                           |
| Управление горячими клавишами   | Горячие клавиши перенесены в отдельный раздел настроек: все действия можно искать, переназначать с проверкой конфликтов, сбрасывать и переносить через экспорт/импорт конфигурации                                                                                                                                                                               |
| Горячие клавиши плеера          | Добавлены настраиваемые команды воспроизведения, очереди, перемотки, громкости, полноэкранного режима, медиатеки, перемешивания, повтора и информации о текущем файле                                                                                                                                                                                              |
