# Новое в версии 1.6.0

| Изменения                               | Что это даёт                                                                                                              |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| Скачивание субтитров                    | В выборе качества появилась вкладка «Субтитры» с сохранением дорожек в формате **.SRT**                                   |
| Cookies для YouTube                     | В настройках загрузчика можно передать cookies из браузера или файла cookies.txt для роликов, требующих вход или проверку |
| Доступность настроек                    | Разделы, выбор языка, темы и размера текста получили управление с клавиатуры и корректные состояния для экранных дикторов |
| **Исправлено** окно настроек            | Escape, клик закрытия и Ctrl/Cmd+, теперь используют единый lifecycle без повторного открытия и потери фокуса             |
| Настройки загрузчика                    | YouTube cookies перенесены в компактный блок дополнительных параметров с отображением текущего режима                     |
| Архитектура настроек                    | Логика YouTube cookies вынесена из общего модуля настроек в отдельный тестируемый компонент                               |
| **Исправлен** веб-интерфейс             | Настройки веб-управления снова показывают переводы, управляют сервером и запускают его после перезапуска приложения       |
| Архитектура настроек                    | Логика веб-управления вынесена в отдельный модуль с защитой от повторной инициализации                                    |
| Архитектура настроек                    | Логика профиля качества загрузки вынесена в отдельный модуль с устойчивым keyboard-state                                  |
| Настройки                               | Информация о приложении перенесена наверх раздела «Общие», а выбор качества загрузки стал компактнее                     |
| Окно выбора качества                    | Активная вкладка типа формата снова показывает текст, остальные остаются компактными иконками с tooltip-подсказками      |
| Окно выбора качества                    | Добавлены плавные анимации открытия модального окна, переключения вкладок и появления превью после загрузки              |
| Настройки                               | Пункт «Веб-интерфейс» теперь свернут по умолчанию и показывает текущий статус в заголовке                                |
| Запуск приложения                       | IPC хранения истории загрузок вынесен в отдельный модуль с проверками load/save/clear/count                              |
| Запуск приложения                       | IPC кеша превью истории вынесен в отдельный модуль с проверками сохранения и удаления превью                             |
| Запуск приложения                       | IPC проверки хешей вынесен в отдельный модуль с проверками выбора файла, инспекции, расчета и прогресса                  |
| Инструменты                             | Управление зависимостями yt-dlp, ffmpeg и Deno перенесено из настроек загрузчика в отдельный инструмент                  |
| Инструменты                             | Карточки инструментов показывают версию, а «Зависимости загрузчика» закреплены первыми с меткой «Новый»                  |
| Media Inspector                         | Добавлено перетаскивание файлов, отображение pixel format и отдельное состояние предупреждений                           |
| Конвертер форматов                      | Добавлен инструмент для конвертации одного локального аудио или видеофайла через `ffmpeg`                                |
| **Исправлена** история загрузок         | Превью больше не перекрывает детали, а кнопка Play открывает скачанный файл вместо просмотра картинки                     |
| **Исправлена** проверка yt-dlp на macOS | Thunder больше не запускает Python-backed `yt-dlp`, чтобы macOS не показывала повторную проверку `Python.framework`       |
