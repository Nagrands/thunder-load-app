# Thunder Logo Rules

## Logo System

- Main logo: Thunder Spark wordmark with the lightning-circle symbol.
- Symbol: standalone lightning bolt inside an energy ring.
- Horizontal logo: symbol left, wordmark right.
- Vertical logo: symbol above wordmark.
- Monochrome logo: single-color mark for constrained surfaces.
- Dark version: light mark on dark backgrounds.
- Light version: dark mark on light backgrounds.
- Favicon: simplified lightning-circle symbol.

## Clear Space

Keep clear space around every logo equal to at least half the symbol width.
Do not place text, controls, badges, or screenshots inside this area.

## Minimum Size

- Symbol: 16 px minimum for favicon-like use.
- Horizontal logo: 120 px minimum width.
- Vertical logo: 96 px minimum width.

## Do Not

- Stretch, rotate, or skew the logo.
- Add unapproved shadows or outlines.
- Change the lightning bolt angle or remove the circular energy ring.
- Place the full-color logo on low-contrast backgrounds.
- Use the old Thunder Load wordmark for new release assets.

## Lockup Copy

- Primary lockup: `THUNDER SPARK`.
- Version chip: `1.6.0`.
- Release tag: `SPARK`.
- Slogan: `Spark ignites the future of downloads.`

## Source Assets

Reusable SVG assets live in `assets/brand/svg/`. Runtime app icons are still
served from `assets/icons/` and generated by `scripts/generate_brand_icons.py`.
