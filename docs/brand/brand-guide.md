# Thunder Brand Guide

Thunder is a focused desktop utility for downloading media and managing local
workflow tools. The 1.6.0 release codename is Thunder Spark.

The visual direction uses a sharp electric-blue lightning symbol inside an open
energy ring, a deep navy technical backdrop, cool white highlights, and a
controlled cyan glow. The release slogan is:

Spark ignites the future of downloads.

## Vision

Make advanced media download and utility workflows feel fast, predictable, and
safe on desktop.

## Mission

Give users one reliable app for media downloads, queue control, history,
runtime tools, and practical file utilities without hiding important state.

## Personality

- Fast: maximum download speed should feel like the default posture.
- Smart: link processing and tool decisions should feel deliberate.
- Reliable: status, errors, and next steps should be explicit.
- Future-facing: the product should look current without sacrificing utility.
- Controlled: destructive or long-running actions should be previewed,
  cancellable, or reversible where possible.

## Values

- Predictability over surprise.
- Utility over decoration.
- Visible state over hidden automation.
- Cross-platform consistency over platform-specific cleverness.
- Recoverability for user data and user actions.

## Design Principles

- Keep the primary task visible.
- Prefer compact, scannable controls for repeated workflows.
- Use color to communicate state and hierarchy, not decoration alone.
- Preserve calm surfaces; reserve glow for the symbol, focus, progress, and
  large release-brand surfaces.
- Keep the core identity blue and cyan. Semantic red, green, and yellow are
  status colors and must not become logo accents.
- Use the lightning symbol as the primary brand signal for Thunder Spark.
- Keep copy direct, action-oriented, and specific.

## Tone Of Voice

- Use short commands for buttons.
- Explain errors with the cause and the next practical action.
- Avoid hype, jokes, and vague success messages.
- In Russian and English, keep product terminology consistent: Thunder for the
  product, Thunder Spark for the 1.6.0 release.
- The slogan is written exactly as `Spark ignites the future of downloads.` in
  English release assets.
