# Thunder Naming Convention

## Product Names

- Product: Thunder.
- Release 1.6.0: Thunder Spark.
- Historical name: Thunder Load.

Use Thunder in new product-facing copy. Use Thunder Load only when referring to
legacy storage paths, historical releases, or compatibility behavior.

## Release Codenames

Major releases may use a codename in product and release materials:

- Thunder Spark
- Thunder Bolt
- Thunder Flash
- Thunder Strike
- Thunder Tempest

## Asset Names

- Use lowercase kebab-case for files.
- Prefix release-specific templates with the codename when needed:
  `spark-release-banner.svg`.
- Keep runtime app icon outputs in existing `assets/icons/` paths.
- Keep reusable brand source assets in `assets/brand/`.

## Copy Rules

- Do not write ThunderLoad or Thunderload in new copy.
- Do not abbreviate the product as TL.
- In user-facing text, write Thunder Spark only when the codename matters.
- Use `Spark ignites the future of downloads.` as the release slogan.
