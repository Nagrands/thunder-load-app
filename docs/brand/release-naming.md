# Thunder Release Naming

Beginning with version 1.6.0, major releases use official codenames.

## Current Release

| Version | Codename | Public Name   |
| ------- | -------- | ------------- |
| 1.6.0   | Spark    | Thunder Spark |

Release slogan: `Spark ignites the future of downloads.`

## Future Codename Pool

- Thunder Bolt
- Thunder Flash
- Thunder Strike
- Thunder Tempest

## Rules

- The product name remains Thunder.
- The codename is used in release notes, banners, splash concepts, and external
  campaign assets.
- Runtime app labels should stay Thunder unless the context is explicitly about
  the release.
- Do not rename data directories, app IDs, update channels, or repositories only
  because a codename changes.
