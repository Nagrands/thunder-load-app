# Thunder Brand Assets

This folder contains reusable Thunder brand sources prepared for Phase 1.

- `svg/` contains source SVG logos, lightning-circle symbol, and template
  surfaces inspired by the Thunder Spark reference board.
- `tokens/` contains documented design token values for later UI phases.
- `src/assets/webfonts/orbitron/` contains self-hosted Orbitron WOFF2
  files used by Thunder Spark wordmarks and brand UI.

Runtime app icon outputs remain in `assets/icons/` and are generated with
`scripts/generate_brand_icons.py`.
