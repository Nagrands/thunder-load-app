## Sources

Player opens local audio and video, folders, single YouTube links, M3U/M3U8, and compatible HTTP(S)/HLS sources.

## Library and playlists

Add files and folders to the library, create persistent playlists, and change display names. Rename affects only the library record.

The **Up Next** queue is separate from playlists, takes playback priority, and does not persist after restart.

## YouTube quality

YouTube offers Auto, Best, Audio, and specific formats. “All qualities” includes choices Thunder can prepare by merging streams or using HLS.

## System integration

Thunder reports metadata, state, and position to the operating system. Media keys control playback, and macOS also provides a Dock menu.

Media that Chromium cannot play directly is prepared through the local FFmpeg/HLS fallback.
