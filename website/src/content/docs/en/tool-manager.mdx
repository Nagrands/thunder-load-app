## Managed dependencies

Thunder manages `yt-dlp`, `ffmpeg`, `ffprobe`, and Deno. The overall status tells you whether dependencies are ready.

## Operations

- inspect availability and versions;
- install a missing tool;
- check for updates;
- reinstall safely;
- move the managed directory;
- reset manager state.

Reinstallation has rollback protection: when a new copy fails validation, Thunder attempts to keep the previous working binary.
