## Add a link

Type, paste, or drop a link into Downloader. After analysis, Thunder shows the title, preview, and available quality choices.

## Choose the output

- **Video** creates a ready-to-play file with audio.
- **Video only** keeps the source video stream.
- **Audio** keeps the source audio track.
- **MP3** creates a converted audio version.
- **Subtitles** saves the selected track as `.srt`.

The actual choices depend on the source and current `yt-dlp` version.

## Queue

Tasks can start immediately or stay in the persistent queue. Thunder prevents duplicates and runs up to two downloads in parallel, depending on your setting.

## History

History supports search, source filters, sorting, repeat download, file and folder actions, and CSV/JSON export. Removing a history record and deleting a local file are separate actions.
