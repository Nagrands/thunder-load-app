## Before you install

Download Thunder only from this site’s **Download** page or the official GitHub Release. The site displays SHA-256 when GitHub provides it in the asset metadata.

Current builds are not digitally signed. Windows SmartScreen or macOS Gatekeeper may therefore ask for additional confirmation.

## Windows

1. Download `Thunder-Load-Setup-*.exe`.
2. Run the installer and approve the User Account Control prompt.
3. Thunder installs for all users, so administrator access is required.
4. Launch Thunder from the Start menu.

Windows 10 and Windows 11 on x64 are supported.

## macOS

1. Choose the DMG for **Apple silicon** or **Intel**.
2. Open the DMG and move Thunder to Applications.
3. On first launch, use Finder’s context menu and choose Open.

macOS 12 and later are supported. Updates on macOS are installed manually from a new DMG.

## Linux

You can build an AppImage from source, but an official automated Linux release is not published yet.
