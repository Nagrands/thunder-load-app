## Initial setup

On first launch, Thunder asks for your language, downloads folder, and managed tools location. You can change all of them later in Settings.

## Prepare the tools

Thunder uses `yt-dlp`, `ffmpeg`, `ffprobe`, and Deno for downloads and media processing. Open the tool manager, check the overall status, and install missing components.

Each tool updates independently. If a reinstall fails, Thunder attempts to preserve the previous working version.

## Your first download

1. Paste a link into Downloader.
2. Wait for the preview and quality list.
3. Choose video, audio, MP3, or subtitles.
4. Add the task to the queue or start immediately.

Thunder preserves the download queue and history, but the Player’s transient queue clears after restart.
