## Shortcut editor

Open Settings → Keyboard shortcuts. Actions are grouped into interface, navigation, downloads, websites, and Player commands.

Choose an action’s edit control, then press the new combination. `Esc` cancels capture. Ordinary actions require `Ctrl`/`Cmd` or `Alt`; `F1`–`F12` are also accepted.

## Conflicts

If a combination is already assigned, Thunder lets you cancel or swap the combinations between actions. Changes apply immediately.

## Export and import

Assignments are included in configuration export. Importing an older file without shortcuts uses platform defaults.

Global commands do not fire while you type in editable fields or record a new shortcut.
