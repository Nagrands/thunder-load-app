## Navigation and search

Settings is organized into General, Downloader, Player, Appearance, Keyboard shortcuts, and Other. Search opens the relevant section and highlights the matched setting.

## Core settings

- language, theme, font size, and visual effects;
- downloads folder and managed tools directory;
- quality profile and parallel download limit;
- clipboard and window behavior;
- Player and keyboard shortcut options;
- access to developer features.

General also shows component versions, release history, update checks, and copyable diagnostics.

## Data

Configuration can be exported and imported. Keep a backup before moving a profile to another computer.
