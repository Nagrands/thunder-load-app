## Prepare

Converter needs a working `ffmpeg`. If it is unavailable, open the tool manager and install or reinstall FFmpeg.

## Convert a file

1. Choose one local audio or video file.
2. Select an output format and available options.
3. Check the destination path.
4. Start the operation and wait for completion.

The source file is not changed. Make sure you have enough free disk space before processing large media.

## Verify the result

Open the finished file in Player or use Media Inspector to verify its container, codecs, and tracks.
