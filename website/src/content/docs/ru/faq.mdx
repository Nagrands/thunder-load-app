## Thunder не видит ссылку

Проверьте подключение, обновите `yt-dlp` в менеджере инструментов и повторите анализ. Некоторые источники требуют cookies, авторизацию или временно меняют свой интерфейс.

## Нет звука или видео

Проверьте FFmpeg и ffprobe. Для форматов, которые Chromium не воспроизводит напрямую, Плеер использует локальный HLS fallback.

## Установщик предупреждает о неизвестном издателе

Текущие Windows и macOS сборки не подписаны. Используйте только файлы с официального GitHub Release и сравните SHA-256, опубликованный на странице загрузки.

## Где хранятся данные

- macOS: `~/Library/Application Support/Thunder Load`
- Windows: `%APPDATA%/Thunder Load`
- Linux: `~/.config/Thunder Load`

Историческое имя папки сохраняется для совместимости обновлений.

## Как сообщить об ошибке

Скопируйте диагностику из Настроек и создайте issue в GitHub-репозитории. Не публикуйте приватные пути, ссылки или cookies.
