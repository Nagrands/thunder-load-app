## Что контролирует менеджер

Thunder управляет `yt-dlp`, `ffmpeg`, `ffprobe` и Deno. Общий статус показывает, готовы ли зависимости к работе.

## Операции

- проверить наличие и версии;
- установить отсутствующий инструмент;
- проверить обновление;
- безопасно переустановить;
- перенести управляемую директорию;
- сбросить состояние менеджера.

Переустановка выполняется с попыткой отката: если новая копия не прошла проверку, Thunder сохраняет предыдущий рабочий бинарник.

## Linux и PATH

На Linux `ffmpeg` и `ffprobe` могут устанавливаться системным package manager. Совместимые инструменты также могут быть найдены через `PATH`.
