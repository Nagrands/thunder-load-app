## Перед установкой

Загружайте Thunder только со страницы **Скачать** этого сайта или из официального GitHub Release. Сайт показывает SHA-256, когда GitHub публикует его в метаданных файла.

Текущие сборки не подписаны цифровым сертификатом. Поэтому Windows SmartScreen или macOS Gatekeeper могут запросить дополнительное подтверждение.

## Windows

1. Скачайте файл `Thunder-Load-Setup-*.exe`.
2. Запустите установщик и подтвердите запрос контроля учётных записей.
3. Thunder устанавливается для всех пользователей компьютера, поэтому требуются права администратора.
4. Запустите приложение через меню «Пуск».

Поддерживаются Windows 10 и Windows 11 на x64.

## macOS

1. Выберите DMG для **Apple silicon** или **Intel**.
2. Откройте DMG и перенесите Thunder в папку Applications.
3. При первом запуске откройте приложение через контекстное меню Finder → «Открыть».

Поддерживается macOS 12 и новее. На macOS обновления устанавливаются вручную из нового DMG.

## Linux

AppImage можно собрать из исходников, но официальный автоматический Linux-релиз пока не публикуется.
